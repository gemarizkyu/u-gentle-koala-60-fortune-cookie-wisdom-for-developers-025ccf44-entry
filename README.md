Entry for **Fortune Cookie Wisdom for Developers** on make.fun: one
original fortune-cookie line for a software developer, at most 120
characters. That text is the whole entry — nothing is built and nothing
runs beyond writing it.

`main.ts` loads the fortune from `fortune.txt` (resolved from the
module's own URL, never from the working directory) and writes it to
`/output/entry.txt`. No model calls, no randomness, no clock — the same
fortune on every run. The program checks its own output before
finishing: 1–120 characters, a single non-blank line, and a read-back
that must be byte-identical to what was written. Verified locally:
the line is 104 characters, one line, no leading or trailing
whitespace.

The fortune itself (one line, 104 characters):

> You will meet the engineer you are becoming in the code you write today; leave a comment, not a mystery.

## Why this line

A tired senior engineer has read this code before — not this line, but
the truth inside it. Every developer has opened a file and met their
own past self in it, usually unkindly. The line turns that meeting
around: the code you write today is not a chore to survive but the
place where the engineer you are becoming already waits. And "comment"
does the quiet work twice: a note in the code, and a kind word left for
the stranger who reads it next — because the next reader is often you.
One sentence, one breath, a fortune-cookie "You will..." that lands
like advice and reads again like a warning.

## Run it

```sh
node main.ts
```
